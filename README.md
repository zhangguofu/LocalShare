# LocalShare

局域网文件与文件夹分享工具 —— Windows / macOS 对等直传，无需公网中转、无需账号。

同一局域网内的两台设备运行本应用，即可互相发现并快速传输文件与文件夹。

## 核心特性

- **对等模式（P2P）**：无中心服务器，两台设备直接互传
- **自动发现**：同子网设备自动出现在列表，也可手动输入 `IP:端口` 直连
- **文件夹完整传输**：保留目录结构（含空目录、中文文件名、零字节文件）
- **接收方确认**：收到传输请求先确认（发送者/内容/大小），接受后才开始传输
- **冲突保护**：目标位置存在同名文件时明确提示，确认后可覆盖，或选择其他位置保存
- **实时进度**：传输列表显示百分比与已传/总字节
- **可配置**：设置页可修改设备名、保存目录、端口

## 获取与安装

到 **GitHub Releases 页** 下载对应平台的安装包：

| 平台 | 安装包 |
|---|---|
| macOS（Apple Silicon） | `LocalShare-<版本>-arm64.dmg` |
| macOS（Intel） | `LocalShare-<版本>-x64.dmg` |
| Windows（64 位） | `LocalShare-<版本>-x64.exe` |

**安装说明**（当前版本未签名，系统会提示"未知开发者"）：

- **macOS**：首次打开若被拦截 → 右键点击应用 → 打开 → 确认；或终端执行 `xattr -cr /Applications/LocalShare.app`
- **Windows**：SmartScreen 提示"未知发布者" → 点击"更多信息" → "仍要运行"

## 使用方式

1. 两台设备（Windows/macOS）连接同一局域网，运行应用，**约 12 秒内**互相出现在设备列表
2. 选择目标设备 → 拖拽文件/文件夹到中间区域（或点击选择）→ 发起传输
3. 接收方弹确认框：**接受**（保存到默认目录）/ **选择其他位置** / **拒绝**；存在同名内容时可选择**接受并覆盖**
4. 传输列表实时显示进度；接收完成有系统通知，点击直达保存目录

**自动发现功能失效时**（跨 VLAN / 无线隔离 / 防火墙拦截广播）：左侧输入 `对方IP:端口`（默认 `45556`）手动直连。

**接收位置**：默认保存到 `~/LocalShare`（设置页可修改）；每次接收都可"选择其他位置"，换位置接收后该位置会成为新的默认保存目录。

## 常见问题

- **两台设备看不到对方？** 确认同一子网、应用在运行；macOS 检查「系统设置 → 隐私与安全性 → 本地网络」已允许；Windows 首次运行防火墙弹窗需勾选"专用网络"。
- **改了 UDP 端口后设备消失了？** UDP 端口是所有设备共用的约定，修改后其他设备无法发现本机（除非对方同样修改）。TCP 端口用于数据传输，每台机器独立，可自由修改。
- **关闭窗口后程序还在？** 这是设计（同类驻留软件惯例）：关闭窗口 = 驻留后台继续接收。macOS 最小化到 Dock；Windows 隐藏到系统托盘，点托盘图标恢复。**最小化后后台可继续工作**。
- **怎么彻底退出？** macOS 按 `Cmd+Q`；Windows 托盘图标右键「退出」。

## 已知限制

- 断点续传：未实现（传输中断后需要重新发送）
- 传输明文，无加密（局域网为可信任环境；接收方确认）
